# Frontend — Banking Fraud Detection System

Static HTML/CSS/JS dashboard for reviewing transactions, viewing fraud scores, and exporting reports.

See the [project README](../README.md) for full setup instructions.

## Quick start

Open `index.html` in a browser, or serve the folder with any static file server. Talks to the backend via `js/api.js` — make sure the backend is running first (`http://127.0.0.1:5000` by default).
